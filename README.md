# 尼罗河惨案 · 人物关系网

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面本体，所有人物、关系、剧情进度都写在里面 |
| `apple-touch-icon.png`（180×180）、`icon-192.png`、`icon-512.png`、`manifest.webmanifest` | 添加到主屏幕时用的图标和名字。iPhone 读的是 `apple-touch-icon.png` 和 `index.html` 里的 `apple-mobile-web-app-title` |
| `sw.js` | 第一次打开后，没网也能看 |
| `index.v1-真相开关版.html` | 上一版：一个“揭示真相”开关，不分步解锁。可以删 |

整个文件夹要一起上传，缺了图标和 `sw.js` 页面也能用，只是不能离线、主屏幕图标会是默认的。

## 发给她之前

1. 把整个文件夹放到任何一个能托管静态网页的地方，拿到一个链接。几个常见的做法：
   - Cloudflare Pages：登录后进入 Workers & Pages，新建 Pages 项目，选 Upload assets，把文件夹拖进去。得到 `xxx.pages.dev`。
   - Netlify：打开 app.netlify.com/drop，把文件夹拖进去。
   - GitHub Pages：建一个仓库，传上去，Settings → Pages 里选分支。
   - 有自己的域名的话，绑一个二级域名（比如 `nile.你的域名`），在国内通常比默认域名稳。
2. 在链接后面加 `#p=步数`，第一次打开就是对的进度。例如读到“沙龙之夜”：`https://你的链接/#p=6`。步数对照在下面。之后进度会存在手机里，不用再带这个后缀。
3. 先用你自己的手机在微信和浏览器各打开一次。

## 怎么用

- 微信里点开链接后，右上角“···”选“在浏览器打开”，用 Safari 打开。
- 在 Safari 里点底部的分享按钮，选“添加到主屏幕”。桌面上的名字是“尼罗河惨案”，图标是黄色六边形里一个“尼”字。以后从桌面图标打开。
- 人物可以拖着摆。松手后会留在原地，只在盖住别人的名字或线上的字时稍微挪开。她摆乱了，在“图例”里点“把人物摆回原来的位置”。
- 页面里有 3 步的新手引导，她点“从头开始看”就行。

步数按网上的章节摘要整理，没有逐章对照她手上那一版。如果某一步解锁得早了或晚了，改 `index.html` 里 `NODES` 和 `EDGES` 中对应条目的第一个数字即可。

## 改内容

- 人名：`NODES` 里每个人的 `short`（图上显示的短名）、`full`（全名，括号里是昵称）、`alt`（别的译本写法，搜索时用）。
- 某一步才显示的文字：`notes` 里 `[步数, '文字']`。
- 关系的名称和颜色会随步数变化：`EDGES` 里的 `states`，格式是 `[步数, '名称', '类型', '箭头方向']`。
- 想用头像代替汉字：在人物上加 `img:'portraits/xxx.png'`。
- 更新页面后，把 `sw.js` 里的 `nile-graph-v2` 改成 `v3`，她下次打开就会拿到新版。
